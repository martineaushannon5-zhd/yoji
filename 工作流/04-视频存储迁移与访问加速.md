# 工作流 04：视频存储迁移与访问加速

> 目标：把视频从 2 核 2G 的服务器本地磁盘挪到对象存储 + CDN，降低服务器磁盘和带宽压力，同时让 App / 后台加载更快。
> 现状结论：**客户端代码不用改**。App 的 `resolveMediaUrl`（entry/src/main/ets/common/Api.ets:217-228）和后台的 `resolveMediaUrl`（yoji-admin/lib/axios.ts）遇到 `http(s)://` 开头的地址会原样返回，只有相对路径才拼 API 域名。所以只要数据库里存的是 CDN 绝对地址，播放就自动走 CDN。

## 1. 现状盘点

| 项目 | 现状 |
| --- | --- |
| 视频落盘 | `server/media/videos/`，Nginx `location /media/ { alias ... }` 直出 |
| 数据库字段 | `videos.video_url`、`videos.thumb_url` 存相对路径，如 `/media/videos/anxiety.mp4` |
| 上传上限 | 900MB（`server/src/routes/admin.js` multer 配置） |
| 实测上传 | 30MB 视频约 25.5 秒（约 9.4Mbps，受服务器上行带宽限制） |
| 服务器 | 阿里云 120.24.171.99，2 核 2G，系统盘 + 数据盘 |
| 线上媒体目录 | `/www/wwwroot/yoji/server/media` |
| 站点配置 | `/www/server/panel/vhost/nginx/node_yoji_project.conf` |

问题很明显：视频越大、人越多，占的是服务器磁盘，走的是服务器带宽；2C2G 小机器的带宽通常只有几 Mbps，几个人同时看就会卡，还会拖慢 API。

## 2. 方案对比

| 方案 | 成本（量级） | 速度 | 改造量 | 适用 |
| --- | --- | --- | --- | --- |
| 继续放服务器 + Nginx 限速 | 0 元 | 取决于服务器带宽，通常最慢 | 无 | 临时 |
| 对象存储 OSS 公共读直链 | 存储 0.12 元/GB/月 + 外网流出约 0.5 元/GB | 较快，无 CDN 边缘缓存 | 改 DB 地址 | 用户少、预算低 |
| **OSS + CDN（推荐）** | CDN 流量约 0.2–0.24 元/GB | 最快，就近节点 | 改 DB 地址 + 配 CDN | 正式使用 |
| 香港/新加坡 OSS + CDN | 略贵，免备案 | 海外快，国内一般 | 同上 | 没有备案域名 |
| Cloudflare R2 + Cloudflare CDN | 存储约 $0.015/GB/月，**出站免费** | 国内访问不稳定 | 同上 | 海外用户为主 |
| 视频平台外链（B站/YouTube） | 0 元 | 不可控，有广告/审核/防盗链 | 大 | 不推荐 |

估算：100GB/月播放流量，CDN 约 20–24 元；1TB/月约 200–240 元。比升级服务器带宽便宜，而且不占服务器磁盘。

## 3. 推荐落地步骤（OSS + CDN）

### 第 0 步：盘点与备份
```bash
du -sh /www/wwwroot/yoji/server/media/videos
ls /www/wwwroot/yoji/server/media/videos | wc -l
# 数据库也备份一份
cp /www/wwwroot/yoji/server/data/yoji.db /www/wwwroot/yoji/server/data/yoji.db.bak-$(date +%Y%m%d)
```

### 第 1 步：开通 OSS
1. 阿里云控制台 → 对象存储 OSS → 创建 Bucket，地域选离用户近的（如深圳/上海）。
2. 读写权限：**公共读**（私有读需要签名 URL，客户端要改，先不做）。
3. 记下 Bucket 域名，如 `yoji-media.oss-cn-shenzhen.aliyuncs.com`。
4. 配置 CORS（后台 Web 端需要）：
   - 来源：`https://yoji.zhdstudy.cyou`、`http://localhost:3000`、`app://-`
   - 方法：GET、HEAD
   - 暴露 Header：`Content-Length`、`Content-Range`、`Accept-Ranges`

### 第 2 步：上传历史视频
```bash
# 安装 ossutil 后配置 AK/SK
ossutil config

# 保持目录结构：/media/videos/xxx.mp4 -> oss://yoji-media/media/videos/xxx.mp4
ossutil cp -r /www/wwwroot/yoji/server/media/ oss://yoji-media/media/ --update
ossutil ls oss://yoji-media/media/videos/ | tail -5
```
传完先别删本地文件，保留 1–2 周做回滚。

### 第 3 步：绑定 CDN 域名
1. CDN 控制台 → 添加域名，如 `media.zhdstudy.cyou`，源站选 OSS 域名。
2. 配置 HTTPS 证书（可用免费证书）。
3. 缓存规则：`*.mp4` 缓存 30 天，`*.jpg/png/webp` 缓存 7 天；开启 Range 回源（视频拖动进度必需）。
4. 可选防盗链：Referer 白名单 + 时间戳鉴权；至少配置用量告警，防止被刷流量。

> 没有备案域名时：可以先用 OSS 默认域名直链（能跑，但阿里云对默认域名有带宽/下载限制，且不适合生产）；或者把 Bucket 放到香港/新加坡。

### 第 4 步：改数据库地址（关键一步）
仓库里已经写好脚本 `server/scripts/rewrite-media-urls.mjs`：

```bash
cd /www/wwwroot/yoji/server

# 先预览，不写库
node scripts/rewrite-media-urls.mjs --to=https://media.zhdstudy.cyou/media

# 确认输出无误后写库（自动备份 .bak-时间戳）
node scripts/rewrite-media-urls.mjs --to=https://media.zhdstudy.cyou/media --apply

# 如果头像也在 /media 下，追加 --include-avatars
```
脚本只改以 `/media` 开头的相对地址，已经是 `http(s)://` 的地址会跳过；写库前自动复制一份数据库备份。

### 第 5 步：验证
1. 后台视频列表能正常显示缩略图。
2. App 首页点开 2–3 个视频，能播放、能拖动进度条（验证 Range）。
3. 浏览器 Network 面板确认请求域名是 `media.zhdstudy.cyou`，状态 200/206。
4. 后台上传一个新视频，确认新文件也进 OSS（见第 6 步）。

### 第 6 步：让“新上传”直接进 OSS（第二阶段）
当前后台上传是先落服务器磁盘再入库。要彻底不占服务器磁盘，需要改成**直传**：
- 后端新增接口 `POST /api/admin/videos/presign`，用 OSS SDK 生成带过期时间的 PUT 签名 URL；
- 前端拿到签名 URL 后直接 `PUT` 文件到 OSS，再把返回的 URL 提交给 `POST /api/admin/videos`；
- 需要给后端加 `ali-oss` 依赖和 AK/SK 环境变量（不要写死在代码里）。

这一步改完后，服务器只负责发签名和存元数据，视频流量完全不经过服务器。

### 第 7 步：回收服务器磁盘
确认线上稳定 1–2 周后：
```bash
# 确认没有漏传
ossutil ls oss://yoji-media/media/videos/ | wc -l
# 再删本地
rm -rf /www/wwwroot/yoji/server/media/videos/*
```
Nginx 的 `/media/` 可以保留作为兜底，也可以改成 302 跳到 CDN：
```nginx
location ^~ /media/videos/ {
    return 302 https://media.zhdstudy.cyou$request_uri;
}
```
这样即使数据库里还有漏改的相对地址，也会被跳到 CDN，不会 404。

## 4. 顺手把视频本身压小

同一段内容，转码后体积通常能降 50%–70%，CDN 流量和加载时间一起降：

```bash
ffmpeg -i input.mp4 \
  -c:v libx264 -crf 24 -preset medium -vf "scale=-2:720" \
  -c:a aac -b:a 96k -movflags +faststart \
  output.mp4
```
- `-crf 24`：画质和体积的平衡点，23–26 之间按需调。
- `scale=-2:720`：720p 足够手机端；宽高比自动保持。
- `+faststart`：把 moov 移到文件头，边下边播，首帧更快。
- 缩略图统一转 WebP（`ffmpeg -ss 00:00:03 -i input.mp4 -frames:v 1 -vf scale=640:-2 thumb.webp`），单张可压到 20KB 左右。

如果以后有长课程视频，再考虑 HLS 切片（`ffmpeg -f hls`），按需加载，不必一次下完整个文件。

## 5. 成本与风险

- **流量费是唯一变量**：按 0.2–0.5 元/GB 估算，100GB/月约 20–50 元。务必在 CDN/OSS 控制台设置**用量告警 + 流量封顶**。
- **防盗链**：公开读的 Bucket 一旦地址泄露，可能被别的站点盗刷。至少开 Referer 白名单；重要内容用签名 URL。
- **备案**：境内 CDN 绑定自定义域名要求域名已备案；`yoji.zhdstudy.cyou` 若已备案则直接可用，否则先用 OSS 默认域名或换香港节点。
- **回滚**：数据库有自动备份，本地文件保留 1–2 周；真出问题把 `--from`/`--to` 反过来再跑一次脚本即可。
- **一致性**：迁移期间如果有人上传新视频，会落到旧目录；建议在低峰期操作，迁移后再统一补传一次。

## 6. 一句话结论

先做“OSS + CDN + 改数据库地址”，一天内能把服务器带宽压力降到接近 0；直传 OSS 和视频转码作为第二阶段，按需再做。
