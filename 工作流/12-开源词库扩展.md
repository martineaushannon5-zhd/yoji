# 12 · 用 GitHub 开源词库扩展 Yoji 词表（2026-11-17）

## 1. 目标与结果

- 目标：在不动 App 代码的前提下，给 Yoji 增加更有区分度的考试词库。
- 结果：新增 2 本、共 **7,928 词**，已导入线上 SQLite 并验证 API：
  - `ielts`：IELTS 雅思词汇，**7,298 词**，带英式音标、中文释义、**双语例句**；
  - `collins5`：柯林斯五星核心词，**630 词**，带音标与中文释义。
- 线上启用词表变为 8 本，合计 **39,237 词**（`cet4` 仍为 `visible=0`，未在本次处理）。

## 3. 转换脚本

`server/scripts/build-wordbooks-from-atlas.py`：把 CSV/JSON 转成 Yoji 词表 JSON（`{id,name,subtitle,description,source,sortOrder,words:[{id,word,phonetic,meaning,example,exampleCn}]}`）。

```bash
python server/scripts/build-wordbooks-from-atlas.py \
  --atlas /tmp/wl2/word-atlas.csv \
  --collins /tmp/wl2/collins.json \
  --out /tmp/wl2/out
# ielts: 7298 词, 1779 KB
# collins5: 630 词, 96 KB
```

字段映射：

| Yoji | word-atlas | collins |
| --- | --- | --- |
| `word` | `word` | `word` |
| `phonetic` | `ipa_uk` | `phonetic` |
| `meaning` | `meanings_zh`（`|` 换成 `；`） | `translation` |
| `example` | `example1_en` | 无 |
| `exampleCn` | `example1_zh` | 无 |
| `id` | `ielts-w0001` 递增 | `collins5-w0001` 递增 |

## 4. 导入与验证

```bash
# 1. 备份线上库
cp /www/wwwroot/yoji/server/data/yoji.db /root/backups/yoji.db.$(date +%Y%m%d%H%M%S)

# 2. 上传 JSON 与导入脚本
scp /tmp/wl2/out/{ielts,collins5}.json root@120.24.171.99:/www/wwwroot/yoji/server/scripts/tmp-wordbooks/
scp server/scripts/import-wordbook-json.js root@120.24.171.99:/www/wwwroot/yoji/server/scripts/

# 3. 导入（整本按 id upsert，重复执行不会叠加）
cd /www/wwwroot/yoji/server
/www/server/nodejs/v24.22.0/bin/node scripts/import-wordbook-json.js scripts/tmp-wordbooks

# 4. 重启并验证
pm2 restart yoji_project
curl -s https://yoji.zhdstudy.cyou/api/wordbooks | python -m json.tool | head -40
curl -s https://yoji.zhdstudy.cyou/api/wordbooks/ielts | head -c 300
```

验证结果（2026-11-17 22:01）：

- `GET /api/wordbooks` 返回 8 本：cet6 2220、cet4-6 8013、highschool 3445、npee 5392、toefl 4510、gre 7729、**ielts 7298**、**collins5 630**；
- `GET /api/wordbooks/ielts` 首词 `library`，含 `example`/`exampleCn`；
- `GET /api/wordbooks/full`：**6,062,041 B**（原 4,142,034 B），Nginx gzip 后 **1,703,517 B**（原约 1.1MB）；
- 线上库备份：`/root/backups/yoji.db.20261117220120`。

## 5. 客户端影响

- App 无需改代码：启动/刷新时 `loadRemoteWordBooks()` 拉 `/api/wordbooks/full`，新词表自动出现在词库选择页。
- 首屏体积从约 1.1MB 涨到约 1.7MB（gzip），4G 下多 1–3 秒；后续可做**按书懒加载**（启动只拉 `/api/wordbooks` 摘要 + 当前书 `/api/wordbooks/:id`，其余按需拉取）或给 `/full` 加 `ETag` 协商缓存。
- 新词的 `statusMap`/`wrongMap` 以 `ielts-w0001` 这类 id 记录；整本重新导入时只要顺序不变，学习进度不会丢。
