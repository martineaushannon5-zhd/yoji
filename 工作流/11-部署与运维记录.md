## 5. `/api` 301 修复

现象：`https://yoji.zhdstudy.cyou/api`（无斜杠）返回 301 到 `/api/`；`/api/` 正常。

处理：在 Nginx 站点配置的 `location /api/ {` 前加精确匹配：

```nginx
location = /api {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

`nginx -t && nginx -s reload` 后 `/api` 直接返回 JSON。配置备份：`/root/backups/node_yoji_project.conf.<时间戳>`。

## 7. 日常发布流程

1. 后端改动：本地 `npm test` → 打包 `server/src` 相关文件 → 备份 → 覆盖 → `pm2 restart yoji_project` → `curl /healthz`、`/api`、目标接口。
2. 后台改动：`NEXT_PUBLIC_API_ORIGIN=https://yoji.zhdstudy.cyou npm run build` → 备份 → 覆盖 `out/` → 强刷浏览器。
3. 桌面端：`cd yoji-admin && npm run electron:build` → 产物在 `dist-release/` → 复制到 `release/`。
4. 发版后检查 PM2 日志：`pm2 logs yoji_project --lines 30`。

## 8. 注意

- `dist-electron` / `dist-installer` 被 Trae、DeepSeek Harness 占用，不要原地覆盖；桌面端统一输出到 `dist-release`。

- OSS 用的 RAM 用户 `deepseekharness` 目前是 `AliyunOSSFullAccess`，后续应收窄为最小权限。
