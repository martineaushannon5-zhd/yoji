# 08 - 后台审计日志与用户导出

> 触发：用户说“后台和 Win 端太肤浅”，要求做成一个像样的后台。  
> 这次先补后台最缺的两块基础能力：**操作留痕**（谁改了什么）和**数据导出**（把用户数据带走做分析）。

## 1. 审计日志

### 后端

`server/src/db.js` 新增表：

```sql
CREATE TABLE IF NOT EXISTS admin_audit_logs (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  account    TEXT NOT NULL DEFAULT '',
  action     TEXT NOT NULL,
  target     TEXT NOT NULL DEFAULT '',
  detail     TEXT NOT NULL DEFAULT '',
  ip         TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_audit_created ON admin_audit_logs(created_at DESC);
```

`recordAuditLog()` 内部 try/catch：审计写失败只打 console，绝不让业务请求 500。`listAuditLogs()` 支持 `action` 前缀过滤、`account` 模糊过滤和分页（上限 100）。

当前埋点：

| action | 触发点 |
| --- | --- |
| `admin.login` / `admin.login.failed` | `server/src/routes/adminPanel.js` 登录成功/失败 |
| `user.delete` | 删除用户 |
| `user.export` | 导出 CSV |
| `video.upload` / `video.create` / `video.update` / `video.delete` | `server/src/routes/admin.js` |
| `wordbook.upload` / `wordbook.update` / `wordbook.delete` | `server/src/routes/adminWordbooks.js` |

`x-admin-token` 运维调用没有账号信息，`account` 记为 `ops`。

接口：

```
GET /api/admin/audit?page=1&pageSize=20&action=video&account=admin
→ { code:0, data:{ logs:[{ id, account, action, target, detail, ip, createdAt }], total, page, pageSize } }
```

### 前端

- `yoji-admin/app/(admin)/audit/page.tsx`：时间、操作人、动作徽章、对象、详情、IP；支持动作前缀筛选、操作人搜索、刷新、分页、骨架屏与空态。
- 侧边栏新增“审计日志”（`ScrollText` 图标）。
- 仪表盘底部新增“最近操作”卡片，30 秒轮询最近 6 条，点击“查看全部”跳审计页。

## 2. 用户 CSV 导出

`GET /api/admin/users/export.csv?search=` 直接返回文件，不走 JSON 信封：

- UTF-8 BOM 开头（`\uFEFF`），Excel 双击打开中文不乱码；
- 列：账号、昵称、已掌握、学习中、连续天数、收藏单词、收藏视频、注册时间、最近学习；
- 单元格含逗号/引号/换行时按 RFC 4180 转义；
- 搜索条件与用户列表一致，导出前会记一条 `user.export` 审计（含行数）。

前端在用户管理页右上角加“导出 CSV”按钮：用 axios `responseType: "blob"` 带上登录 token，前端 `URL.createObjectURL` 触发下载。

## 3. 文档同步

- `server/src/openapi.js` 新增 `/api/admin/audit`、`/api/admin/users/export.csv`，现在 38 个 operation（32 个 path，含 OSS 直传签名）。
- 顺手修正了一处漂移：用户列表查询参数原来写的是 `keyword`，实际后端读 `search`，已改正并补上 `pageSize` 上限 50。
