调试设备安装

  1. 手机进入「设置 → 关于手机」，连续点版本号开启开发者模式，并打开 USB 调试。
  2. 电脑安装 DevEco Studio 自带的 hdc，连接手机后执行 hdc list targets 确认识别。
  3. 执行 hdc install yoji-1.3.0.hap；提示签名或设备未授权，说明该设备未登记在调试证书里。
