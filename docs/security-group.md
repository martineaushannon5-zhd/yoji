# 安全组与端口配置（阿里云 ECS）

> 当前服务器：`120.24.171.99`（阿里云深圳）
> 已确认：`80`、`443`、`22` 可用；后台视频上传走 `https://域名/api/...`，不需要额外开放端口。

## 一、推荐入方向规则

| 端口 | 协议 | 授权对象 | 用途 |
| --- | --- | --- | --- |
| 22 | TCP | **只填你的办公/家庭公网 IP** | SSH 管理 |
| 80 | TCP | `0.0.0.0/0` | HTTP；备案期间用服务器 IP 访问 |
| 443 | TCP | `0.0.0.0/0` | HTTPS；后台和 API |
| 3000 | TCP | **不要开放** | Node 只监听 127.0.0.1 |
| 8888 / 888 / 8443 | TCP | **不要对公网开放** | 宝塔面板端口，建议只允许自己的 IP |

出方向保持默认 `全部允许` 即可。

## 二、阿里云控制台操作

1. 登录阿里云 → **ECS 实例** → 找到 `120.24.171.99`；
2. 点实例 → **安全组** → 配置规则；
3. **入方向** → 手动添加：
   - `22/tcp`，授权对象填自己的公网 IP（不要用 `0.0.0.0/0`）；
   - `80/tcp`，`0.0.0.0/0`；
   - `443/tcp`，`0.0.0.0/0`；
4. 如果已有 `3000`、`8888`、`888` 对 `0.0.0.0/0` 的规则，删除或改成自己的 IP；
5. 保存后立即生效，不需要重启服务器。

## 三、视频上传需要改安全组吗？

**不需要。**

- 上传请求走 `443`（域名）或 `80`（IP）；
- 单个视频最大 900MB，限制在 Nginx/Node：
  - Nginx `/api/`：`client_max_body_size 1024m`；
  - Node Multer：`fileSize: 900MB`；
- 安全组只控制端口，不限制请求体大小；
- 不要为了上传单独开放 3000 端口。
