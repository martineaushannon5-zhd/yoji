## 后端新增字段

`server/src/progress.js` 的进度快照新增：

- `nickname`
- `gender`
- `birthday`
- `favoriteVideos`
- `customWords`

合并规则：资料字段客户端非空优先；视频收藏并集；自填单词按 id 并集（客户端覆盖同 id）。同步时会把 `nickname` 回写 `users` 表，后台用户列表能直接看到昵称。

> **线上服务器需要重新部署 `server/`**（至少更新 `src/progress.js`、`src/routes/progress.js`、`src/db.js` 并重启 Node），否则这些新字段不会进云端；旧后端下客户端会保留本地新字段，不会丢，但换设备无法恢复。
